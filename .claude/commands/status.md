description: Tóm tắt tình trạng dự án VeriClue
---

Chạy `uv run python scripts/plan_check.py` (bảng trạng thái, tải, đường găng). Đọc `docs/status/STATUS.md` và 5 bàn giao mới nhất (`uv run python scripts/new_handoff.py --latest 5`). Trả lời bằng tiếng Việt, tối đa 15 dòng:

1. Đang ở sprint nào, còn bao nhiêu ngày tới mốc kế tiếp và tới hạn nộp 06/11.
2. Số task theo trạng thái: done / doing / review / todo / blocked.
3. Các task đang bị chặn và lý do.
4. Các task trên đường găng (critical path) chưa xong.
5. Câu hỏi mở cần nhóm quyết.
6. Đề xuất 3 việc nên làm tiếp theo.
