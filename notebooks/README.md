# notebooks — Thử nghiệm

- Đặt tên `NN-<chủ-đề>-<tên-người>.ipynb`, ví dụ `03-chromapulse-lag-quan.ipynb`.
- Xóa output trước khi commit (`uv run nbstripout --install` sau khi setup), hoặc chỉ commit notebook nhỏ.
- Notebook **không phải code sản phẩm**. Khi một thử nghiệm thành công, chuyển code vào `ml/src/` kèm test, rồi ghi kết quả vào `docs/status/STATUS.md` hoặc ADR.
