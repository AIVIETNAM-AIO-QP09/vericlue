# Ảnh ứng dụng dùng trong README

Bốn ảnh PNG là snapshot giao diện Compose, dữ liệu tổng hợp, được sao chép
nguyên byte từ bộ review UI ngày 04/11/2026. Không phải ảnh sinh bằng AI hoặc
bản ghi của một lượt xác minh người thật.

| File | Nội dung |
|---|---|
| `login.png` | Đăng nhập lần đầu, chưa điền thông tin |
| `identity-card.png` | Hướng dẫn quét, không có ảnh căn cước thật |
| `face-challenge.png` | Hướng dẫn quay đầu với hình đại diện tổng hợp |
| `profile.png` | Hồ sơ với tên và mã tài khoản minh họa |

[provenance.json](provenance.json) ghi commit nguồn, tên snapshot và SHA-256.
Ảnh có thể khác các build mới hơn; không dùng ảnh để xác nhận mức nghiệm thu
AI, thời hạn hoặc chính sách vận hành hiện tại.

Khi thay ảnh, dùng snapshot mới có dữ liệu tổng hợp, kiểm bằng mắt, cập nhật
nguồn/checksum và chú thích ngày trong README gốc. Không đưa ảnh camera, mặt,
căn cước, QR, số điện thoại hoặc token thật vào bộ ảnh này.

Quyền đối với tài sản do nhóm tạo theo LICENSE gốc; thành phần bên thứ ba
trong ứng dụng giữ các quyền và notice tương ứng.
